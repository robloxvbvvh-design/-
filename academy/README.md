# Академия мистера Ворона

Учебное приложение по английскому в одном HTML-файле.

1. Выбираешь цель: ЕГЭ (желаемый балл) или обычный английский (свой уровень).
2. Вводишь e-mail или продолжаешь без него (адрес хранится только в браузере).
3. Выбираешь режим учителя: строгий, романтический, добрый, пиратский, шекспировский, безумный профессор.
4. Из цели и режима собирается план уроков.
5. Появляется странный человек — мистер Ворон — и ведёт урок. В строгом режиме за любую ошибку орёт.

## Голос
- Учитель говорит вслух (Web Speech API, `speechSynthesis`).
- Ученик отвечает голосом (кнопка микрофона, `SpeechRecognition`; работает в Chrome/Edge/Safari).
- Режим «без рук»: после ответа учителя микрофон включается сам.
- Настройки и прогресс запоминаются в `localStorage`.

## Кто учит
- В чате Claude (как артефакт) учителя играет Claude из чата.
- Локально (`index.html` в браузере) — по ключу Claude API из настроек, либо встроенный офлайн-учитель.

## Файлы
- `app.html` — исходник страницы (для публикации как артефакт).
- `index.html` — тот же код с обёрткой `<!doctype html>`, открывается прямо в браузере.
