# VPN-бот для Happ

Telegram-бот, который продаёт подписку на VPN. Клиент — **Happ** (iOS/Android/Windows/macOS):
бот выдаёт ссылку-подписку, Happ подтягивает из неё все 10 серверов.

## Что умеет
- **Старт**: предлагает пробный период на 3 дня или отказаться.
- **🌍 Серверы**: список из 10 серверов + кнопка «Подключить в Happ».
- **👤 Профиль**: Telegram ID, срок подписки, ссылка подписки.
- **💳 Продлить**: месяц — 100 ₽, год — 1 000 ₽, навсегда — 10 000 ₽ (оплата через Telegram Payments, например ЮKassa).
- **👆 Тапалка**: 1 клик = 1 минута подписки. Вывести в подписку можно, когда натапано от 1 дня (1440 кликов).
- **⚙️ Настройки**: уведомления о конце подписки вкл/выкл, сброс ссылки подписки.
- Админ-команда `/give <id> <дней|forever>`.

## Ключи серверов
Ключи (`vless://`, `vmess://`, `trojan://`, `ss://`) берутся из `servers.json` — это должны быть
**ваши собственные** серверы. Проще всего поднять VPS и поставить панель
[3x-ui](https://github.com/MHSanaei/3x-ui) или [Marzban](https://github.com/Gozargah/Marzban),
создать inbound VLESS Reality и скопировать ссылку.

```bash
cp servers.example.json servers.json   # вписать свои 10 ключей
```

## Запуск
```bash
cd vpnbot
pip install -r requirements.txt
cp .env.example .env                   # BOT_TOKEN, PROVIDER_TOKEN, PUBLIC_URL, ADMINS
python bot.py
```
Сервер подписок слушает порт `SUB_PORT` (по умолчанию 8080). `PUBLIC_URL` должен вести на него
(лучше через nginx + HTTPS), иначе Happ не сможет загрузить подписку.

Когда подписка заканчивается, ссылка начинает отдавать пустой список — серверы в Happ пропадают
после обновления подписки.
