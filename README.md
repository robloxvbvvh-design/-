# Тимофей в 90-х — мультфильм с субтитрами

Мультфильм по озвучке: персонажи ходят и действуют по сюжету, внизу караоке-субтитры (произносимое слово загорается красным).

- `video.mp4` — готовый мультфильм 1080×1920 со звуком
- `index.html` — тот же мультфильм в браузере (рисуется вживую под звук)
- `anim/scene.js` — все сцены и персонажи (квартира, мама, двор, фото, ларёк «Хлеб», портал, змейка, ночь)
- `subtitles_only.mp4` — первая версия: только субтитры
- `subtitles.ass` / `subtitles.srt` / `words.json` — субтитры и тайминг каждого слова

Расшифровка сделана моделью GigaAM v2 (sherpa-onnx, скачана с GitHub), сырые тайминги — `words_raw.json`.

Пересобрать: `python3 scripts/build.py && node scripts/render_anim.js` (нужны ffmpeg и playwright).
