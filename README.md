# Чернобыль, 01:23 — как выжить при аварии на АЭС

Анимация с голосовой озвучкой о взрыве на Чернобыльской АЭС 26 апреля 1986 года
и о том, как защититься от радиации при аварии.

Откройте `index.html` в браузере и нажмите «Смотреть со звуком».

- 8 анимированных сцен (Canvas): взрыв, укрытие, окна, одежда и душ, йод, еда, эвакуация, три правила.
- Голос — встроенный синтезатор речи браузера (Web Speech API, русский голос), субтитры всегда на экране.
- Звук счётчика Гейгера (Web Audio), шкала опасности (условная).
- Без зависимостей, один файл.
