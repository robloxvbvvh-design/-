# Зомби-шутер 3D

Браузерный 3D-шутер от первого лица на [Three.js](https://threejs.org/): отбивайтесь от волн зомби на ночном пустыре.

Работает на компьютере (клавиатура + мышь) и на телефоне (сенсорный джойстик и кнопки).

## Запуск

Игра использует ES-модули, поэтому её нужно открыть через локальный веб-сервер (а не двойным кликом по файлу):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Three.js подгружается с CDN (unpkg), так что нужен интернет.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | прицел |
| ЛКМ (удерживать) | стрельба |
| R | перезарядка |
| Shift | бег |
| Пробел | прыжок |
| Esc | пауза |
| B | магазин (между волнами) |
| N | начать волну сразу |

## Особенности

### Сюжет: 4 главы

Лаборатория «Генезис» под Новоградом-4 выпустила вирус Ч-4. Ты держишь периметр, пока доктор Орлова ищет источник заражения. Каждая глава — 5 волн и босс в конце, после 4-й главы открывается бесконечный режим.

| Глава | Волны | Босс | Особенность босса |
|---|---|---|---|
| 1. Карантин | 1–5 | Мясник | мощные удары вблизи |
| 2. Кислотный дождь | 6–10 | Королева плевунов | держит дистанцию, плюётся веером кислоты |
| 3. Чёрный батальон | 11–15 | Генерал Громов | бронирован, делает рывки на игрока |
| 4. Нулевой пациент | 16–20 | Нулевой пациент | рывки, кислота и призыв бегунов |

### Перерыв между волнами и магазин

После каждой волны — 25 секунд передышки, затем следующая волна начинается сама (или сразу — кнопка «Начать волну» / N). Во время перерыва открыт магазин (B или кнопка «Магазин»):

- оружие (в начале есть только пистолет), пополнение патронов;
- аптечка (+50) и большая аптечка (полное здоровье);
- бронежилет (+50) и тяжёлая броня (до 100) — броня принимает на себя 70% урона;
- ящик патронов ко всему оружию.

Деньги дают за убийства (хедшот — вдвое больше) и за пройденные волны.

### 8 видов зомби

- **Зомби** — обычный.
- **Бегун** (с волны 2) — быстрый и хрупкий.
- **Ползун** (с волны 2) — ползёт по земле, в него трудно попасть.
- **Плевун** (с волны 3) — держит дистанцию и плюётся кислотой.
- **Взрывун** (с волны 3) — взрывается рядом с игроком; если убить издалека, взрыв заденет других зомби.
- **Спецназ** (с волны 4) — в каске и бронежилете, тело получает 40% урона, цельтесь в лицо.
- **Громила** (с волны 4) — большой, медленный и живучий.
- **Боссы** — каждую 5-ю волну, по одному на главу (см. выше).

### Прочее

- Бесконечные волны: с каждой волной зомби больше, они быстрее и крепче.
- Хедшоты наносят ×2.5 урона и дают двойные очки.
- Из зомби выпадают патроны и аптечки.
- Препятствия (ящики, стены, машины, деревья) блокируют движение и пули.
- Процедурные звуки через Web Audio API — без внешних файлов.

### На телефоне

Слева — джойстик движения (отведите до упора, чтобы бежать), свайп по правой части экрана — прицел, кнопки «ОГОНЬ», «R» (перезарядка), «⤒» (прыжок) и «❚❚» (пауза). Лучше держать телефон горизонтально.

## Производительность

На телефоне игра автоматически включает облегчённую графику: без теней и динамического света, пониженное разрешение. Если FPS всё равно ниже 50, разрешение снижается дальше. Текущий FPS показан вверху экрана.
