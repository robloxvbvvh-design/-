# Злой бот для Telegram

Нажимаешь /start, пишешь что угодно — бот отвечает максимально зло.
Отвечает на текст, фото, видео, кружочки и гифки.

## Запуск

Ничего устанавливать не нужно, только Python.

1. Открой `bot.py` и вставь токен в строку `TOKEN = ""` (или положи рядом файл `.env` со строкой `BOT_TOKEN=...`).
2. Запусти `python bot.py`.
3. Должно появиться «Бот @... запущен!». Если что-то не так — он напишет ошибку.

Токен не коммить.
