# Заводные: Ночная смена

Оригинальная 3D-игра в жанре «выживание на ночной смене» (Three.js, один HTML-файл).

Вы — ночной сторож закрытой фабрики игрушек «Часовой двор». Продержитесь с 00:00 до 06:00:
следите за камерами, закрывайте двери и люк вентиляции, экономьте заряд.

**Запуск:** откройте `index.html` в браузере (нужен интернет для загрузки Three.js с cdnjs).

## Управление
| Клавиша | Действие |
|---|---|
| Мышь у края экрана / свайп | осмотреться (вверх — люк) |
| Q / E | левая / правая дверь |
| A / D | свет в левом / правом проёме |
| W | люк вентиляции |
| Пробел | планшет с камерами, 1–6 — выбор камеры |
| M | звук вкл/выкл |

## Обитатели
- **Капрал Винт** — жестяной солдатик, левая дверь.
- **Мадам Пуант** — фарфоровая балерина, правая дверь; замирает под камерой.
- **Попрыгун** — шкатулка на складе (CAM 02), заводится, когда на неё не смотрят.
- **Маэстро Гарди** — шарманщик в вентиляции; заиграла музыка — закройте люк.

5 ночей + открываемая 6-я. Прогресс сохраняется в браузере.
