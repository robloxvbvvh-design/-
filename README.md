# Claude Code — видео по озвучке

Вертикальное видео 1080×1920, собранное на HTML/CSS/JavaScript и синхронизированное с голосом (`assets/voice.mp3`).

- `index.html`: откройте и нажмите «Смотреть». Кадры и караоке-субтитры идут по `audio.currentTime`, а текущее слово горит красным.
- `video.mp4`: готовый ролик с озвучкой.

Сцены: монтажная («Это видео не я создавал») → текст перекрывает экран («Это Claude Code») → персонаж + субтитры/картинки/персонажи → персонаж за компьютером создаёт кадры и субтитры → окно ввода с моделью Opus 5.5 → «Загрузите файл», отправка, шкала загрузки.

Тайминги слов лежат в `PHRASES` в `script.js`. Чтобы перерендерить отдельный кадр, откройте `index.html?capture=1` и вызовите `renderAt(t)`.

## Тутор: видео без монтажа (`tutorial/`)

Второй ролик по озвучке `assets/voice-tutorial.mp3`: ElevenLabs (иконка, выбор голоса, текст, «Создать», «Слушать») → Claude Code (запрос и файлы) → видео создаётся и скачивается → иконка монтажа перечёркнута крестом.

- `tutorial/index.html`: просмотр в браузере.
- `tutorial/video-tutorial.mp4`: готовый ролик.
