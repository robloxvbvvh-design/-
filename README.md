# Тимофей в 90-х — анимированные субтитры

Караоке-субтитры к озвучке: произносимое слово загорается красным.

- `video.mp4` — готовое вертикальное видео 1080×1920 с субтитрами
- `index.html` — веб-версия (открыть в браузере рядом с `audio.mp3`)
- `subtitles.ass` — анимированные субтитры (можно наложить в любом редакторе / ffmpeg)
- `subtitles.srt` — обычные субтитры по строкам
- `words.json` — тайминг каждого слова

Расшифровка сделана моделью GigaAM v2 (sherpa-onnx, скачана с GitHub), сырые тайминги — `words_raw.json`.
Пересобрать: `scripts/render.sh`.
