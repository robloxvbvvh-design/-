# Зомби-шутер 3D

Браузерный 3D-шутер от первого лица на [Three.js](https://threejs.org/): отбивайтесь от волн зомби на ночном пустыре.

Работает на компьютере (клавиатура + мышь) и на телефоне (сенсорный джойстик и кнопки).

## Запуск

Игра использует ES-модули, поэтому её нужно открыть через локальный веб-сервер (а не двойным кликом по файлу):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

Three.js подгружается с CDN (unpkg), так что нужен интернет.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Мышь | прицел |
| ЛКМ (удерживать) | стрельба |
| R | перезарядка |
| Shift | бег |
| Пробел | прыжок |
| Esc | пауза |

## Особенности

- Бесконечные волны: с каждой волной зомби больше, они быстрее и крепче.
- Три вида зомби: обычный, бегун (быстрый, хрупкий) и громила (медленный, очень живучий).
- Хедшоты наносят ×2.5 урона и дают двойные очки.
- Из зомби выпадают патроны и аптечки.
- Препятствия (ящики, стены, машины, деревья) блокируют движение и пули.
- Процедурные звуки через Web Audio API — без внешних файлов.

### На телефоне

Слева — джойстик движения (отведите до упора, чтобы бежать), свайп по правой части экрана — прицел, кнопки «ОГОНЬ», «R» (перезарядка), «⤒» (прыжок) и «❚❚» (пауза). Лучше держать телефон горизонтально.
