# 🛡️ ВПН Кликер

Тапай кнопку → копи минуты ВПН → покупай скины → выводи минуты на один из 10 серверов Shadowsocks и подключайся через приложение **Happ**.

## Как это работает
- **1 тап = 1 минута ВПН** (защита от автокликера: максимум 15 тапов/сек).
- **Скины** (8 штук) покупаются за минуты и меняют вид кнопки.
- **Вывод** — минимум 60 минут. Пакеты: 1 ч, 3 ч, 12 ч, сутки, неделя.
- После вывода появляется ключ `ss://...` и кнопка **«Открыть в Happ»** — ключ сам добавится в приложение. Повторный вывод на тот же сервер продлевает доступ.

## Запуск (нужен только Node.js 18+)
```bash
node server.js
```
Открыть: http://localhost:3000 (порт можно сменить: `PORT=8080 node server.js`).

## Подключить свои серверы
Откройте `config/servers.json` и замените `host`, `port`, `method`, `password` на данные своих Shadowsocks-серверов.
Можно вместо этого вставить готовый ключ: `"ssKey": "ss://..."`.

Скины и цены — в `config/skins.json`. Правила (минуты за тап, минимум вывода, пакеты) — вверху `server.js`.

## ⚠️ Важно
Сейчас таймер доступа считается **в приложении**: Shadowsocks-ключ сам по себе не «сгорает».
Чтобы доступ реально отключался по истечении минут, нужна панель управления сервером
(например 3x-ui, Marzban или Outline), которая выдаёт каждому игроку отдельный ключ с лимитом по времени.
Это можно подключить в функции `POST /api/withdraw` в `server.js`.
