# Ночной агент идей для видео

Пока ты спишь, агент каждую ночь:

1. **Ищет залетевшие видео** — тренды YouTube и поиск по твоим запросам за последние дни.
   Считает, какие ролики «выстрелили» сильнее всего: просмотры в час и во сколько раз
   просмотры превысили число подписчиков канала.
2. **Разбирает, почему они залетели**, и придумывает свои оригинальные идеи на тех же механиках.
3. **Пишет сценарий с раскадровкой** — по сценам: таймкод, что в кадре, текст на экране, текст диктора, звук.
4. **Озвучивает** каждый сценарий голосом (mp3).

Утром результат лежит в папке `output/ГГГГ-ММ-ДД/`:

| Файл | Что внутри |
|---|---|
| `README.md` | что сейчас в трендах + список идей |
| `01-....md` | сценарий и раскадровка одной идеи |
| `01-....mp3` | озвучка этой идеи |
| `videos.json` / `videos.md` | найденные залетевшие видео |
| `scripts.json` | всё то же в формате JSON |

## Как включить (один раз)

1. **Ключ Claude.** Получи API-ключ на https://platform.claude.com и добавь его в репозиторий:
   *Settings → Secrets and variables → Actions → New repository secret*, имя `ANTHROPIC_API_KEY`.
2. **Ключ YouTube (рекомендуется, бесплатно).** В Google Cloud Console включи
   *YouTube Data API v3*, создай API key и добавь секрет `YOUTUBE_API_KEY`.
   Без него агент ищет залетевшие видео через веб-поиск — работает, но менее точно.
3. **Настрой нишу** в `config.yaml`: тема канала, поисковые запросы, сколько идей в ночь, голос.
4. Слей ветку в основную (`main`) — GitHub запускает ночные задачи только оттуда.
   Проверить сразу можно во вкладке *Actions → Ночной агент идей → Run workflow*.

## Локальный запуск

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...
export YOUTUBE_API_KEY=...   # необязательно
python -m agent.main
```

## Настройки

- Время запуска — строка `cron` в `.github/workflows/nightly.yml` (время в UTC).
- Голоса: `ru-RU-DmitryNeural` (мужской), `ru-RU-SvetlanaNeural` (женский).
  Скорость речи — `voice_rate`.
- `shorts_only: false` — искать не только короткие видео.
