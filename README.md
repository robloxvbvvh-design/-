# 🛡️ ВПН Кликер

Тапай кнопку → копи минуты ВПН → покупай скины → выводи минуты на один из 10 серверов Shadowsocks и подключайся через приложение **Happ**.

## Как это работает
- **1 тап = 1 минута ВПН** (защита от автокликера: максимум 15 тапов/сек).
- **Скины** (8 штук) покупаются за минуты и меняют вид кнопки.
- **Вывод** — минимум 60 минут. Пакеты: 1 ч, 3 ч, 12 ч, сутки, неделя. Время добавляется к вашей подписке.

## Связь с Happ (подписка)
У каждого игрока есть личная ссылка-подписка `/sub/<id>` (вкладка **Happ** → «Добавить в Happ»).
Добавляете её в Happ один раз, и дальше Happ сам показывает:
- **дату окончания ВПН** — столько, сколько вы вывели минут;
- **объявление** с вашей статистикой: «✅ ВПН ещё 1ч 0м · Натапано: 60 · Баланс: 0 мин».

Пока время есть, в подписке 10 серверов. Когда время кончилось — серверов нет.
Happ сам обновляет подписку раз в час; чтобы увидеть новые минуты сразу — обновите подписку в Happ вручную.

**Важно:** телефон с Happ должен видеть сервер. `localhost` с телефона не откроется — запускайте
сервер на компьютере в той же Wi-Fi сети и заходите по его IP (например `http://192.168.1.5:3000`),
либо выложите сервер в интернет (например через бесплатный туннель `cloudflared tunnel --url http://localhost:3000`)
и укажите адрес: `PUBLIC_URL=https://ваш-адрес node server.js`.

## Запуск (нужен только Node.js 18+)
```bash
node server.js
```
Открыть: http://localhost:3000 (порт можно сменить: `PORT=8080 node server.js`).

## Серверы — бесплатно, ничего настраивать не надо
Приложение само скачивает публичные списки бесплатных Shadowsocks-серверов с GitHub:
- [barry-far/V2ray-Config](https://github.com/barry-far/V2ray-Config)
- [mahdibland/V2RayAggregator](https://github.com/mahdibland/V2RayAggregator)

Оно проверяет, какие серверы отвечают, и берёт 10 рабочих (по возможности из разных стран).
Список обновляется каждые 30 минут. Источники можно поменять в `freeServers.js`.

**Минусы бесплатных серверов:** они медленные, часто умирают, и их владельцы неизвестны —
не заходите через них в банк и не вводите пароли.

### Свои серверы (по желанию)
Если появится свой сервер — впишите его в `config/servers.json` вместо заглушки `*.example.com`
(`host`, `port`, `method`, `password` или готовый `"ssKey": "ss://..."`). Свои серверы стоят первыми,
остальные места добиваются бесплатными.

Скины и цены — в `config/skins.json`. Правила (минуты за тап, минимум вывода, пакеты) — вверху `server.js`.

## ⚠️ Ограничения
Ключи бесплатных серверов публичные: подписка убирает серверы из Happ, когда время кончилось,
но уже скачанный ключ технически можно использовать дальше (до часа — пока Happ не обновит подписку).
Настоящее отключение по времени возможно только на своих серверах с панелью (3x-ui, Marzban, Outline).
